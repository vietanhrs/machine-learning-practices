# Machine Learning Practices

A structured, hands-on learning repository covering core machine learning concepts, techniques, and applications. Each section contains **teaching notes**, **quizzes**, and **coding exercises** to maximize your understanding.

---

## Repository Structure

```
machine-learning-practices/
├── 01_ml_models/               # Clustering, Logistic Regression, Decision Tree, Collaborative Filtering
├── 02_neural_networks/         # Feedforward, CNN, RNN, Transformer
├── 03_ml_techniques/           # Supervised/Unsupervised, Gradient Descent, Loss Functions, Regularization
├── 04_parameters_benchmarks/   # Accuracy, F1, Precision, Recall, MSE, Log-Likelihood, ROC/AUC
├── 05_statistics/              # Variance, Probability, Normal & Long-tail Distributions
└── 06_ml_tasks/                # Language Modeling, Anomaly Detection, Object Classification, Machine Translation
```

## How to Use This Repo

1. **Read** the `README.md` in each folder to learn the concepts.
2. **Test yourself** with `quiz.md` — answer in a separate file or on paper.
3. **Complete** the coding exercises in the `exercises/` folder. Each file has `TODO` markers and function stubs for you to implement.
4. Follow the **reference links** at the bottom of each README for deeper study.

## Tips for Effective Learning

- Do not skip the exercises — implementation is the best way to internalize concepts.
- After each section, try to explain the concept in your own words (Feynman technique).
- Return to the quizzes after a few days to test long-term retention.
